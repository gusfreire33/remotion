# editor/ (app Remotion)

⛔ **Antes de qualquer edição de vídeo, leia e siga `PLAYBOOK.md` (nesta pasta) à risca.**
É o processo validado pelo dono (Etapas 0–12). Não pule a revisão (stills + Studio) e não rode
o render final sem o "ok" dele.

- Rodar comandos a partir desta pasta. Windows + PowerShell: use sempre `-LiteralPath`.
- `npm run dev` → `http://localhost:3000/MeuVideo`. Após mudanças: `npx tsc --noEmit` (exit 0).
